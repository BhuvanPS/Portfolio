Liver Cirrhosis Survival Prediction Analysis

A Machine Learning Approach to Patient Outcome Forecasting

View Repository on GitHub

Project Goal

The objective of this project was to build and evaluate predictive models for forecasting the survival outcome of patients with liver cirrhosis. This involved extensive data cleaning, feature engineering, and rigorous model selection to identify the most accurate and reliable classification method. The final model predicts one of three survival outcomes: **D** (Death), **C** (Censored/Transplant), or **O** (Censored/No Transplant).

Methodology & Workflow

Data Preparation

  • Handling missing values and outliers.
  • Categorical feature encoding (One-Hot, Label).
  • Feature scaling using `StandardScaler`.
  • 70/30 Train-Test split for robust evaluation.

Model Selection

  • Tested models: Logistic Regression, Ridge Classifier, SVC.
  • Class imbalance addressed with class weighting.
  • Hyperparameter tuning using `GridSearchCV`.
  • 5-Fold Cross-Validation for unbiased scoring.

Feature Importance

  • ANOVA F-value (SelectKBest) for univariate selection.
  • Permutation Importance for model-agnostic feature ranking.
  • Reduced feature set from 20+ to 35 encoded features.
  • Identified key clinical indicators for survival.
